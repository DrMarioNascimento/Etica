# Mosaico Vila Ética

Jogo de turma (telão + celulares) em que a turma é uma vila e os grupos são famílias, com o vocabulário técnico da ética em cada momento, glossário no celular e Momento do Lazer.

Cópia de publicação trazida do repositório `lab-ra` (pasta `mosaico-vila-etica`, commit `8e92156`, 15/11/2026). A versão de projeto (documentação, testes e origens dos ícones) fica no `lab-ra`.

Pasta independente, como as demais aplicações do site: fontes Sora e JetBrains Mono locais em `assets/fontes/` (licença OFL incluída), sem serviços externos.
